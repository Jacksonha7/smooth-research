# smooth-research

我在读博过程中学到的、真正能让科研更顺畅的小技巧。每一条都是我自己跑通过的流程，写成新手照着做就能复现的教程。

## 目录

| # | 技巧 | 解决什么问题 |
| --- | --- | --- |
| 01 | [让 Claude 直接编辑你的 Overleaf 论文](tips/01-claude-code-edit-overleaf.md) | 不用再在 Overleaf 和 Claude 之间一句一句复制粘贴 |

## 约定

- 每条技巧一个文件，放在 `tips/` 下，按 `编号-简短英文名.md` 命名。
- 每篇开头先讲痛点和效果，再讲原理，最后是可照做的步骤和避坑。
- 涉及第三方工具的地方附上官方来源链接，方便日后核对是否过时。
