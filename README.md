## 约定

- 工具教程放在 `tips/`，经验分享放在 `experience/`，各自按 `编号-简短英文名.md` 命名，编号分开计。
- 工具教程开头先讲痛点和效果，再讲原理，最后是可照做的步骤和避坑；涉及第三方工具的地方附上官方来源链接，方便日后核对是否过时。
- 经验分享保留第一人称和原本的口吻，只做分段和错字整理，不改观点。
